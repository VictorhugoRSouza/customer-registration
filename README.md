# Cadastro de Clientes

Sistema de gerenciamento de clientes desenvolvido em Java, com o objetivo de praticar conceitos fundamentais da linguagem e de Programação Orientada a Objetos.

## Sobre o projeto

O Customer Management System é uma aplicação executada no console que permite realizar o cadastro e o gerenciamento de clientes.

O projeto foi desenvolvido durante meus estudos de Java, colocando em prática conceitos de lógica de programação, estruturas de controle, classes, objetos e coleções.

## Funcionalidades

- Cadastro de clientes
- Listagem de clientes cadastrados
- Consulta de clientes
- Gerenciamento de informações dos clientes
- Interação através do console

## Tecnologias utilizadas

- Java
- Eclipse IDE
- Git
- GitHub
